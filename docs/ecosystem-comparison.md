# Ecosystem Comparison

This page keeps the comparison narrow and technical.

## LangGraph

Useful for graph-shaped workflows and explicit state transitions. NANO Agent Stack is more opinionated about organizational hierarchy and department-based routing.

## CrewAI

Useful for rapid assembly of role-based agent teams. NANO Agent Stack stays lower-level and puts more emphasis on infrastructure boundaries such as policies, memory interfaces, provider abstraction, and observability.

## AutoGen

Useful for flexible multi-agent interactions and conversational loops. NANO Agent Stack is more focused on auditable workflow structure than on broad agent conversation patterns.

## Summary

NANO Agent Stack aims to be a compact orchestration layer for builders who want reusable multi-agent patterns with explicit runtime seams, not the broadest agent platform.
